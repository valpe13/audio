SVD-XT · balanced · 25 frames · 6 fps · 20 steps

Grok Imagine Video settings

To enable: select “Grok Imagine Video (xAI API)” in the Workflow / video backend dropdown above, then Save settings. Uses the project Grok/xAI API key or XAI_API_KEY.

Hosted xAI image-to-video backend. Queuing generation may make a paid API call. Use diagnostics before bulk generation; this UI never runs generation until you press group video buttons.

For less camera movement, use “Object motion — locked camera” or “Ambient nature” and keep group animation prompts explicit: locked camera, static camera, no camera movement; animate objects only, leaves swaying, grass moving, water ripples, smoke drifting, fire flicker. Negative prompt terms should include camera pan, camera zoom, camera orbit, dolly, drift, whole image moving. SVD may still drift because it is image-conditioned; AnimateDiff can follow text/object motion better, but usually needs masks, ControlNet, or IPAdapter for reliable isolated object motion.

Target duration extends the generated MP4 cheaply with VideoHelperSuite repeats/ping-pong of the sampled motion; it does not create extra unique SVD frames. For 1-minute landscape loops, use “Landscape long loop” or raise Frames manually: it creates more unique SVD frames but lowers steps and may be slower or slightly softer. Loop playback speed affects only browser preview video elements, not the generated file.

Practical quality path: keep SVD-XT for mass production and RealVisXL image fidelity; use SD1.5 AnimateDiff only for experiments where prompt/object motion matters more than matching the source image. Use generated_hotshotxl only after checking /api/comfyui/animatediff-sdxl/diagnostics: it needs AnimateDiff-Evolved, VideoHelperSuite, RealVisXL/another SDXL checkpoint, and an SDXL-compatible motion model such as HotshotXL under ComfyUI/models/animatediff_models.

Grok Imagine Video uses /api/xai/imagine-video/diagnostics for setup checks. Confirmed settings are model grok-imagine-video, aspect ratios 16:9/9:16, and resolutions 480p/720p; 1080p is not exposed until official docs confirm it. Prompt-only looping is not guaranteed, so Grok videos default to ffmpeg ping-pong post-processing after download; use crossfade only when forward motion is more important than seam reliability.
