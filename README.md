# Audio Studio — установка и восстановление

Локальная студия озвучки: русский синтез речи, проекты, монтаж и экспорт аудио/видео.

## Установка на другой компьютер с Windows

1. Скачайте [Audio-Setup.zip из последнего релиза](https://github.com/valpe13/audio/releases/latest/download/Audio-Setup.zip).
2. Распакуйте **весь архив** в отдельную папку, например `C:\AudioStudio`. Не запускайте файлы прямо из ZIP.
3. Запустите **START.cmd**. Интернет нужен для загрузки Docker, библиотек и голосовой модели.
4. Если Windows/Docker потребует перезагрузку, перезагрузите компьютер и снова запустите `START.cmd`.
5. После успешной проверки откроется [студия](http://localhost:7870/studio/).

Нужны Windows с поддержкой Docker Desktop / WSL 2, включённая виртуализация и
**не менее 25 ГБ свободного места** для сборки и кэша. Видеокарта для первого
запуска не обязательна. Первая установка может занять десятки минут.

Вместо релизного архива можно скачать **Code → Download ZIP**, распаковать и
запустить тот же `START.cmd`. Git и отдельная установка Python для этого пути не нужны.

Установка считается успешной только после запуска сервисов и реального теста
синтеза русской речи. При ошибке окно покажет причину; повторный запуск использует
уже скачанные зависимости. Лог сборки можно сохранить командой
`docker compose build --progress plain > build.log 2>&1` из папки программы.

## Что работает после базовой установки

- Studio и Silero: русская речь без загрузки собственного образца голоса.
- XTTS: доступен в настройках после добавления WAV-образца; первая генерация
  скачает модель. См. [настройку XTTS и GPU](README_DOCKER.md).
- Аудиоэкспорт; видеоэкспорт из добавленных в проект изображений/видео.
- Grok/xAI: дополнительные возможности требуют вашего API-ключа.
- Fish Speech по умолчанию — **заглушка API**. Реальная генерация Fish требует
  отдельного runtime и checkpoint; базовая установка её не обещает.
- Локальная генерация картинок/видео через ComfyUI — отдельная тяжёлая установка.
  Полный Windows-установщик `audio_xtts_universal_installer.cmd` сохранён для неё;
  [подробности](README_REFERENCE.md). Его не нужно запускать поверх Docker для
  обычной озвучки. Наличие моделей в Releases само по себе не проверяет GPU на вашем ПК.

## Повторный запуск и остановка

После установки запускайте `START.cmd` из этой же папки.
Чтобы остановить студию: `docker compose down`. Проекты сохраняются в `docker-data`.
Не удаляйте эту папку, если хотите сохранить созданные материалы.

Для обновления git-клона: `install_docker_stack.cmd -UpdateProject`.
При установке из ZIP распакуйте новую версию в отдельную папку и перенесите туда
`docker-data` и свой `.env` после остановки старой версии.

## Где что хранится

- В этом репозитории: актуальные исходники, установщики и инструкции.
- В [GitHub Releases](https://github.com/valpe13/audio/releases): архив программы,
  XTTS-ресурсы, ComfyUI portable и крупные модели. Их не нужно добавлять в Git/LFS.
- Личные записи, API-ключи, проекты, кэши и окружения Python не входят в исходники.
- [README_DOCKER.md](README_DOCKER.md): ручная установка Linux/Windows, GPU и настройки.
- [README_REFERENCE.md](README_REFERENCE.md): расширенная документация и прежние эксперименты.
- [README_OFFLINE_INSTALL.md](README_OFFLINE_INSTALL.md): сборка отдельного offline-пакета.
  Обычный Audio-Setup.zip требует интернета и не является offline-пакетом.
- [runtime-snapshots](runtime-snapshots/): версии дополнительных runtime и сохранённые
  локальные правки перед очисткой исходного компьютера.
